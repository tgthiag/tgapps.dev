SEO & GEO Health Report – Tg Apps

Key Observations

Strengths

  • Localized content (EN/PT) already wired into src/i18n/translations.ts.
  • Structured sections with semantic IDs for anchor-based navigation.
  • Contact info repeated in header, hero, footer, and contact block.

Risks

  • Static <head> in index.html uses mixed language text with encoding issues; no canonical, hreflang, or OG/Twitter image.
  • No structured data (Organization/LocalBusiness) or geo meta tags; NAP not machine-readable.
  • Navigation uses <button> elements instead of <a> anchors, hurting crawlability.

Action Plan

  1. Implement dynamic head + locale routing: React Helmet, canonical/hreflang tags, localized meta descriptions.
  2. Add Organization/LocalBusiness JSON-LD: Include coordinates, address (São Paulo), phone, sameAs profiles.
  3. Convert nav buttons to anchors + update footer links: ensures crawlability and UX consistency.
  4. Create dedicated EN/PT URLs & sitemap: Allows search engines to index both locales; submit via GSC.
  5. Optimize hero/About media & OG/Twitter cards: Provide compressed assets, loading="lazy", and shareable preview images.
  6. Publish geo meta & GBP references: Use geo.position, ICBM, and link to Google Business profile or map embed.
